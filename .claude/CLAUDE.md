## Project

`@flowscripter/template-bun-wasm-rust-library` - Project template for a Rust library compiled to WASM exposed as a Bun module. Demonstrates building Rust with wasm-pack, exposing it via TypeScript, and testing with Bun.

## Commands

```bash
# Install dependencies
bun install

# Build WASM (requires wasm-pack: cargo install wasm-pack)
wasm-pack build --target web --release --no-pack && rm pkg/.gitignore

# Test
cargo test && bun test

# Format
bunx oxfmt

# Lint
cargo fmt && bunx oxlint index.ts src/ tests/

# Generate API documentation
bunx typedoc --readme none index.ts
```

## Architecture

- `index.ts` -- public entry point; re-exports from `src/lib.ts`
- `src/lib.ts` -- TypeScript wrapper that loads and instantiates the WASM module from `pkg/`
- `src/lib.rs` -- Rust source compiled to WASM via wasm-pack; exports `world()` function
- `tests/world_test.ts` -- Bun unit tests for the TypeScript/WASM interface
- `tests/integration_test.rs` -- Rust integration tests
- `pkg/` -- generated by wasm-pack (not committed); contains the compiled WASM and JS bindings
- `Cargo.toml` -- Rust project config with wasm-bindgen dependency
